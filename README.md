# Nexa AI

Nexa AI is an intelligent live streaming and engagement platform with real-time analytics, automated campaign tracking, and conversational AI tools.

## Project Structure

- **`app/`**: Cross-platform frontend application built with Expo (React Native & Web), TailwindCSS / NativeWind, and TypeScript.
- **`server/`**: Scalable backend API service built with NestJS, TypeScript, and MongoDB.

## Getting Started

### 1. Backend Server (`server`)

```bash
cd server
npm install
npm run start:dev
```

### 2. Frontend Application (`app`)

```bash
cd app
npm install
npx expo start
```
